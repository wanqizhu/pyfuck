怎么用

python app.py 启动本服务 → 页面里编码 → 下载得到 pyfuck_output.py → 拿到任何装了 CPython 的机器上 python pyfuck_output.py，输出与原程序完全相同。 生成物只有一个表达式，形如 eval(…"exec"…)(…)，不依赖本项目的任何文件。

工作原理（四层构造）

① all([])=True / all([[]])=False，加 + 得到整数 0、1，再相加得到任意整数 → ② 用这些整数给 str(str)、str(eval)、str(str.count) 的结果取下标，得到字符 c u n f o ' . h； 字母 t r a v e l s 直接可用，于是拼出 chr 与 str → ③ chr(N) 拿到任意字符，用 + 拼出任意字符串 → ④ 把整份源码变成一个字符串，用 eval("exec")(源码字符串) 执行，即可支持 def/for/import 等任意语句。

注意

输出体积膨胀很大（本例约 300×），且运行时会做大量 eval，适合演示与出题，不适合真实项目； 页面上的「语法自检」只 compile 不执行你的代码。
